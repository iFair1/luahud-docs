Options for `lh.draw(value, options)` and `lh.drawln(value, options)`. Every field is optional. Color and shadow overrides apply only to this call; later calls keep the section defaults. Colors use RGB/ARGB hex strings or ARGB integers.

## Fields

<TypeFields id="TextOptions" />

## Defaults and behavior

`textColor`, `backgroundColor`, and `shadow` inherit from the current section. Local offsets default to `0`. Overrides apply to this call only.

## Example

```lua
lh.draw("Warning: ", { textColor = "#FF5555", shadow = true })
lh.drawln("Low health")
```

Use `lh.drawln()` for a line break. Text options have no `newLine` field. In a section, set text scale on [SectionOptions](/options/section-options/). Inside a [canvas](/canvas/getting-started/), use `lh.draw()` with `x`, `y`, `scale`, and optional rotation; line breaks are not supported. Unknown option fields produce an error.
