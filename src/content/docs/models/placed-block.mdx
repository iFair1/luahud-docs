`lh.getBlockAt()`, `lh.pos.highestBlock`, and `lh.facing.getTargetBlock()` return a Block model. Check for `nil` when a lookup can miss. Pass a world block directly to [`lh.drawBlock()`](/api/#api-lh-drawBlock) to preserve its block state.

## Fields

<TypeFields id="Block" />

Block state property values are strings. For example, a block with a `waterlogged` property returns `"true"` or `"false"` for that property. `breakProgress` ranges from 0 to 1 for the block the local player is breaking and is 0 otherwise.

## BlockInput

<TypeFields id="BlockInput" />

Pass a block ID directly to draw its default state. Use a table with `id` and optional `properties` to start from that default state and override individual properties. Property names and values must be valid for the chosen block.

```lua
lh.drawBlock({
    id = "minecraft:oak_stairs",
    properties = { facing = "east", half = "top" },
}, { scale = 2 })
```
