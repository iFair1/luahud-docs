To open the mod screen:
- press H in-game or
- use [Mod Menu](https://modrinth.com/mod/modmenu)
![LuaHUD Menu. References on top left, buttons on top right, list of profiles in the middle, and "Open Folder" and "Done" buttons on the bottom](/src/assets/menu.png)

Profiles are .lua files at `<minecraft directory>/config/luahud/`. You can easily open it in your file manager by clicking open folder on the mod screen

:::tip
Profiles update on every change on .lua files. But it's recommended to do file operations from the gui so your settings such as keybind, visibility, active/disabled, order doesn't reset.
:::

:::tip
I also **highly** recommend that you open the profile directory instead of individual files, so you can use dynamically generated API definitions.
:::
