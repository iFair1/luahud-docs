[Lua](https://www.lua.org) is a lightweight programming language first released in 1993. It was designed to be embedded in other applications, where it can add scripting and customization without requiring a large runtime.

Lua has a small, approachable core and a straightforward syntax, which makes it relatively easy to learn. It is also known for its speed and compact interpreter, making it a practical choice for applications with limited resources.

The language is commonly used in games, tools, and other software that benefits from flexible scripting. Developers can use Lua to define behavior or automate tasks while keeping the main application written in another language. Its tables are a central data structure and can be used to represent lists, maps, and objects.

Lua is designed to work alongside a host application: that application decides which features and APIs are available to scripts. This makes Lua adaptable to many different projects, while keeping the language itself small and portable.
